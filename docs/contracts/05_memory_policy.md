# 05 Memory Policy v1

## 四动作

```text
WRITE   仅用户明确表达（“记住…”）
UPDATE  仅用户明确纠正（“我不是 XX，现在叫 YY”）
RECALL  与当前问题相关时自动召回，top-k ≤3
DELETE  用户明确表达（“忘掉…”）
```

## 写入规则

- V1 禁止 LLM 自动写入、禁止候选队列。
- 不记录情绪、一次性事件、未确认偏好。
- 相似记忆合并更新（相似度阈值 + importance 加权），不追加重复条目。
- 支持过期、低 importance 降权、显式删除与可审计清单。
- 所有记忆 org+user 隔离。

## 注入顺序（固定，不可无限增长）

```text
System prompt → 用户记忆(≤3) → 会话摘要 → 最近 N 轮 → 当前输入
```

## 边界

- 个人记忆 ≠ 知识库 ≠ 执行状态 ≠ 缓存 ≠ 审计。
