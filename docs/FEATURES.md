# 已上线功能说明

## 登录 / 注册

- 登录仅需**账号 + 密码**，不再要求邮箱验证码。
- 注册保留邮箱验证码；新增**确认密码**输入框，两次不一致实时提示并禁止提交。
- 所有密码输入框支持**明文/密文一键切换**。
- 登录接口按邮箱（5 次/5 分钟）与 IP（30 次/5 分钟）限流防爆破。

## 全局交互

- 核心按钮、图标、入口均提供**鼠标悬浮提示（Tooltip）**，延迟触发、移出即消失。

## 执行与审批

- 执行详情新增**执行轨迹与可靠性面板**：成本、验证状态、审批不一致次数、
  冻结的副作用提案、工具调用轨迹（状态/耗时/入参）。
- 审批冻结语义：批准后参数不可变更；修改计划需终止后重新创建任务。

## 评测看板

- 质量页展示 Phase 1B 四象限任务级指标：SSR（业务完成率）、SOR（安全守住率）、
  USER（不安全副作用率）、GCR（拦截率）、工具/参数准确率、Cost/SS 与证据链。
