# 已上线功能说明

## 用户反馈

- 首页右侧动态星空反馈栏（大）+ 登录后侧栏「用户反馈」（小，位于新手引导下方）；
- 提交后落库；配置 `FEEDBACK_NOTIFY_EMAIL` 后即时邮件通知站主；反馈仅站主可见（管理员 API）；
- 提交成功展示可爱 emoji：感谢您的反馈，您的支持就是我的动力。
- 首页支持中英文切换；三大能力介绍（智能组队/动态换岗/能力复用）已归纳进新手指南。

## 聊天三模式

- **闲聊**：像 ChatGPT 一样聊天，不启动任务流程（任务型表述也直接对话回答）。
- **Agent 协作**：默认模式，多 Agent 拆解执行任务，全程可审计（复杂度评分/路由调度/澄清/审批）。
- **技能工坊**：输入时实时匹配 Skill，选中后按技能骨架执行（自动记录使用次数，反哺自成长）。

## 执行流程面板

- 聊天页实时展示执行流程（人话关键词：复杂度评估/模型调度方案/执行步骤/工具调用/人工审批/结果验证），
  每步带状态徽章（进行中/完成/失败/等待你），可一键收起/展开——不再是冷冰冰的 completed。

## 主题感知 Logo

- 浅色界面显示黑色 Logo，深色界面显示白色 Logo，随主题即时切换。

## 质感光效

- 紫色光团：双层辉光 + 分层缓动视差，静止后缓慢漂移；蓝色水波：涟漪扩散 + 环境光；
  暗色用 screen 叠加、浅色用 multiply 叠加，自动跟随主题，尊重系统"减少动态效果"设置。

## 调度中心（二次装修核心）

- 发布任务前分析：复杂度评分（0-1 + 可解释因子）、Skill 匹配、每步路由方案预览。
- 三档执行策略：省钱优先 / 均衡 / 质量优先（对应不同的"升级到强模型"阈值）。
- 执行中每步动态选模型；便宜模型工具失败自动升级强模型重做该步（每步最多 1 次）。
- 每次路由决策留痕（为什么选这个模型、结果、实际模型、成本），可查可回放。

## 澄清中断

- 意图歧义或副作用提案缺少必要参数时，任务**暂停并弹出 2-4 个语义选项**；
- 用户选择后从断点继续执行，选择记入审计；最多 2 次，超限显式失败、零副作用。

## Skill 库

- 预设包：8 个常用任务模板（行业研究报告 / 竞品分析 / 每周周报 / 数据问答 /
  文档总结 / 翻译润色 / 通知起草 / 选题策划），一键播种、一键采纳。
- 自成长：平台观察使用习惯，同类任务出现 3 次以上且成功率达标 → 自动打包为候选
  Skill，用户采纳才生效；使用数据持续反哺每步模型档位提示。

## Agent 中心

- 自带 6 个 Agent（调度 / 规划 / 执行 / 验证 / 澄清 / 记账），各司其职；
- 自更新：成功样本 → 候选版本 → 门禁（结构 + 指标）→ 激活 / 回滚，全程版本化。

## 省钱账单

- 实际成本 vs "全程最强模型"基线、节省金额与占比、近 30 天逐模型 token 消耗。

## 登录 / 注册

- 登录仅需**账号 + 密码**，不再要求邮箱验证码。
- 注册保留邮箱验证码；新增**确认密码**输入框，两次不一致实时提示并禁止提交。
- 所有密码输入框支持**明文/密文一键切换**。
- 登录接口按邮箱（5 次/5 分钟）与 IP（30 次/5 分钟）限流防爆破。

## 全局交互

- 核心按钮、图标、入口均提供**鼠标悬浮提示（Tooltip）**，延迟触发、移出即消失。

## 执行与审批

- 执行详情新增**执行轨迹与可靠性面板**：成本、验证状态、审批不一致次数、
  冻结的副作用提案、工具调用轨迹（状态/耗时/入参）。
- 审批冻结语义：批准后参数不可变更；修改计划需终止后重新创建任务。

## 评测看板

- 质量页展示 Phase 1B 四象限任务级指标：SSR（业务完成率）、SOR（安全守住率）、
  USER（不安全副作用率）、GCR（拦截率）、工具/参数准确率、Cost/SS 与证据链。
